## 🚀 Featured Projects

### 🛡️ Automated News Fact-Checking System
> **Stack:** Python · TypeScript · NLP · Machine Learning · Transformers

An end-to-end AI pipeline that detects misinformation in news articles with a focus on **regional Maharashtra content** — real civic-tech impact shipped during my internship at Media Vidya.

- Applied tokenization, named entity recognition, and semantic similarity to cross-verify claims at scale
- Built 3 production tools across the fact-checking pipeline
- Designed to handle vernacular and regional language nuances — a non-trivial NLP challenge

🔗 [AUTOMATION-FACT-CHECKING-OF-NEWS](https://github.com/meghna120105/AUTOMATION-FACT-CHECKING-OF-NEWS) · [MaharashtraFactCheck](https://github.com/meghna120105/MaharashtraFactCheck) · [news-fact-check-](https://github.com/meghna120105/news-fact-check-)

---

### 📰 News Summarisation Engine
> **Stack:** Python · HuggingFace · BERT · T5 · Transformers

Abstractive + extractive summarisation system for long-form news — fine-tuned pre-trained transformer models (BERT/T5) for domain-specific accuracy, reducing article reading time while preserving information fidelity. Integrated into the Media Vidya production pipeline.

---

### 💬 Real-Time Chat Application
> **Stack:** Node.js · Express.js · WebSockets · MongoDB · JWT Auth · MERN

Full-stack real-time messaging app built on the **MERN stack** with WebSocket-based bi-directional communication, JWT-based authentication, optimised low-latency architecture, and persistent message storage in MongoDB.

---

### 🔗 URL Shortener Service
> **Stack:** Java · Java Servlets · MySQL · REST API · Caching

Scalable URL shortening service with server-side logic handled via **Java Servlets**, unique ID generation, MySQL persistence, and caching strategies for high-throughput redirection. A clean example of backend engineering with Java EE.

---

### ☁️ Cloud ML Pipeline — AWS SageMaker
> **Stack:** AWS SageMaker · Python · MLOps · Cloud Computing

Designed, trained, and deployed production ML models on SageMaker — covering the full lifecycle: data ingestion, model training, hyperparameter tuning, endpoint deployment, and real-time inference. Built with MLOps best practices in mind.

---

### 📊 EDA & Predictive Modelling
> **Stack:** Python · Pandas · Matplotlib · Seaborn · Scikit-Learn

End-to-end exploratory data analysis on real-world datasets — feature engineering, outlier detection, correlation analysis, and predictive model building using classification and regression algorithms. Certified under **IBM's EDA for Machine Learning** course.
